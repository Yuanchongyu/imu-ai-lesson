# IMU AI 课程：从倾斜滚球到动作分类

用XIAO nRF52840 Sense这块IMU芯片，带学生走完四个循序渐进的小项目：

```
01_倾斜滚球 → 02_数据可视化 → 03_计步器 → 04_动作分类
   (先玩)      (看懂数据)      (写规则)     (训练AI)
```

每一步都比上一步难一点点：先靠手感建立"这东西能感觉到动作"的直觉，再看懂动作变成了什么数字，再学会用一条简单规则处理这些数字，最后才真正训练一个AI模型去做规则写不出来的事。

---

## ⚠️ 最重要的一件事：不能直接双击打开网页文件

这几个网页都用到 **Web Serial API**（浏览器直接读取硬件的串口数据），这个功能**只在"安全环境"下才能用**——直接双击HTML文件打开（网址栏显示 `file://...`）不算安全环境，连接按钮点了也没用。必须用下面两种方式之一打开：

### 方式A（推荐）：用 GitHub Pages 直接打开网址，换电脑也不用重新配置

把这个仓库推到GitHub后，在仓库的 **Settings → Pages → Build and deployment → Deploy from a branch → 选 `main` 分支、根目录 `/`** ，保存后等一两分钟，就能直接用网址打开：

```
https://<你的GitHub用户名>.github.io/<仓库名>/01_倾斜滚球/
https://<你的GitHub用户名>.github.io/<仓库名>/02_数据可视化/
https://<你的GitHub用户名>.github.io/<仓库名>/03_计步器/
https://<你的GitHub用户名>.github.io/<仓库名>/04_动作分类/
```

这是`https://`网址，天然满足"安全环境"要求，**换Windows还是Mac都一样，只要有网、开着Chrome或Edge就能用**，这也是为什么要先做这一步把项目推上GitHub——不只是备份代码，更是为了让它能跨电脑直接用。

### 方式B（没网络时的备用方案）：本地起一个网页服务器

在这个文件夹里打开终端（Mac叫"终端"，Windows叫命令提示符/PowerShell），运行：

```bash
# Mac / Linux（一般自带 python3，不用额外装）
python3 -m http.server 8000

# 如果 python3 不存在，试试
python -m http.server 8000
```

然后浏览器打开 `http://localhost:8000/01_倾斜滚球/`，这样也满足"安全环境"要求。

**每个网页顶部我都加了自动检测**：如果不小心还是双击打开了文件，页面会弹出一条红色提示条告诉你该怎么做，不会是"点了没反应"式的沉默失败。

## 硬件准备（每次换电脑通用）

1. 装 [Arduino IDE](https://www.arduino.cc/en/software)（Mac/Windows都有）
2. Arduino IDE 里装好 Seeed nRF52 板卡支持包 + `Seeed_Arduino_LSM6DS3` 库
3. 把 `firmware/imu_stream.ino` 烧到 XIAO nRF52840 Sense 上
4. 打开 Arduino 的串口监视器确认能看到 `x,y,z` 数字在跳动，再关掉串口监视器（**串口同时只能被一个程序占用**，串口监视器开着的话网页会连不上）
5. 用 Chrome 或 Edge 打开对应步骤的网址（Web Serial **不支持Safari**，Mac上默认浏览器是Safari，记得手动换成Chrome）
